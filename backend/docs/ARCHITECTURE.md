# Backend

`src/videos/videos.controller.ts` только принимает HTTP-запросы. DTO и глобальный `ValidationPipe` проверяют входные данные. `VideosService` реализует чтение каталога, импорт, синхронизацию и получение playback, используя `PrismaService` и `RutubeService`. `RutubeService` валидирует URL/ID, ограничивает запросы доменом RUTUBE, нормализует поля и обрабатывает 404, timeout, неверный JSON и сетевые ошибки. Глобальный exception filter возвращает единый JSON `{statusCode,message}`; неизвестные ошибки дают 500.

`prisma/schema.prisma` содержит `Video`, уникальный `externalId` и индекс `searchTitle`. `prisma/migrations` — версионируемая схема SQLite. `scripts/seed-legacy.ts` переносит исторические ID без mock-метаданных: данные запрашиваются у RUTUBE, а карта `legacy-video-ids.ts` хранит только соответствие ID. Новый ID — детерминированный `rutube-<externalId>`. `upsert` предотвращает дубли при повторном импорте.

Каталог и поиск не обращаются к RUTUBE. Обложки проксируются через `/videos/:id/thumbnail` с доверенного CDN без записи файлов. Playback обращается к RUTUBE каждый раз и не сохраняется. Нестабильность внешнего сервиса не прерывает работу базы и чтение уже импортированного каталога. API слушает `0.0.0.0`, что позволяет подключить устройство в локальной сети при правильной конфигурации клиента и сетевого доступа.
