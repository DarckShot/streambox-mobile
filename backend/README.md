# StreamBox Backend

Здесь будет находиться серверная часть StreamBox.

## Текущее состояние

Backend ещё не реализован. В каталоге нет исходного кода, конфигурации сборки, зависимостей или команд запуска. Язык и фреймворк также не выбраны.

До принятия технических решений нельзя считать упомянутые в архитектурных документах API, базу данных, авторизацию или фоновые задачи реализованными.

## Перед началом разработки

Нужно определить:

- функциональные требования и границы backend;
- язык, фреймворк и систему сборки;
- формат API и способ ведения контракта;
- модель данных и хранилище;
- авторизацию и управление доступом;
- конфигурацию окружений и секретов;
- стратегию тестирования;
- контейнеризацию, CI/CD, мониторинг и развёртывание.

Принятые решения следует зафиксировать в [архитектуре backend](docs/ARCHITECTURE.md), а команды установки и запуска — в этом README.
